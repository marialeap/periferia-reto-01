# Conocimiento de negocio: registro como proveedor
- Solicitante: cliente que quiere registrar a Periferia como proveedor.
- Fuente única de datos: fixtures/reto-01/repositorio/maestro.json, con sinónimos en glosario-campos.json.
- CO usa NIT; EC, PE, PA usan RUC; HN usa RTN. La fuente solo contiene NIT colombiano: para otro país se solicita confirmación del identificador extranjero.
- P0 Excel: usar hoja y coordenadas de cada plantilla. P1 PDF: respetar orden de campos. P2 portal: solo listado de valores para copiar, sin login ni automatización.
- Soporte vencido/ausente bloquea listo_para_firma; campo faltante no bloquea, pero se reporta.
- La firma y el envío real son decisiones humanas y no forman parte de este reto. El correo de borrador no contiene datos bancarios.
